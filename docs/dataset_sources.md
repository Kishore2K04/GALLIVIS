# GALLIVIS Dataset Sources

## Ultrasound Auxiliary Dataset

Dataset:
UIdataGB

Purpose:
Ultrasound image pipeline development and experimentation.

Important:
This dataset contains gallstone-related ultrasound images but does not provide verified Cholesterol/Pigment/Mixed gallstone composition labels.

Therefore, it must not be used to claim that an individual image represents a particular gallstone composition.

Storage:
data/raw/ultrasound/

Processing:
data/processed/ultrasound/
