# GALLIVIS

## Gallstone Intelligent Vision System

An Intelligent Multimodal Clinical Decision Support System for Pre-operative Gallstone Classification.

## Project Status

Under Development

## Objective

GALLIVIS is an AI-powered clinical decision support system designed to analyze relevant pre-operative medical information and assist clinicians in predicting gallstone type with an explainable confidence score.

## Predicted Classes

- Cholesterol Gallstone
- Pigment Gallstone
- Mixed Gallstone

## Core Components

- Ultrasound Image Analysis
- Multimodal Clinical Data Analysis
- Confidence Score
- Explainable AI
- Missing Information Detection
- Clinical Report Generation

## Technology Stack

- Python
- TensorFlow / PyTorch
- OpenCV
- Grad-CAM
- Streamlit
- FastAPI
- PostgreSQL
- Docker
