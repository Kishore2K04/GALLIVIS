# GALLIVIS Data

This directory contains data used by the GALLIVIS development pipeline.

## Structure

### raw/

Original datasets are stored here without modification.

- ultrasound/
- clinical/
- spectroscopy/

### processed/

Processed copies generated by the GALLIVIS pipeline.

- ultrasound/
- clinical/

### metadata/

Dataset descriptions, registries, labels, and supporting metadata.

## Important

Raw data must not be modified directly.

The final three-class gallstone composition classifier requires reliable ground-truth labels:

- Cholesterol
- Pigment
- Mixed

A dataset containing only "gallstone present" does not provide sufficient information to train this three-class composition classifier.
